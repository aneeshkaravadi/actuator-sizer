# For the Machina Labs team

This repo turns a robot task into joint torque, speed and thermal requirements with MuJoCo inverse dynamics. It includes a parametric actuator envelope in CAD (STEP). The same approach applies to sizing the joints of a forming cell's robot arms for a given toolpath and forming force.

**A 3-week project I could do for you, remote:** compute joint torque and thermal margins for a robot arm following a sample incremental-forming toolpath under a specified tool force, to flag the joints and path segments that limit speed.
