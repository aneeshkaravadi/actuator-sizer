# For the Figure team

This is a task-to-actuator pipeline for a humanoid:
- MuJoCo inverse dynamics of a 25 kg tote lift, with balance checked through the centre of pressure
- per-joint torque, speed and power requirements
- gear-ratio trades (heat vs reflected inertia vs speed)
- winding-temperature limits for a repeated shuttle task
- series-elastic impact protection

All tested against closed-form checks (joint work = ΔPE within 1%).

**A 3-week project I could do for you, remote:** a requirement-envelope and thermal-duty study for a task set you choose, with a ranked list of the joint and actuator changes that most improve sustained throughput.
